## Convenção de nome de arquivo

Todo arquivo de evidência segue o padrão:

`YYYY-MM-DD-<descricao-curta-em-kebab-case>.<ext>`

Exemplos: `2026-08-28-matching-retorna-top-5.png`, `2026-08-28-demo-completo.mp4`

Sempre que o demo for re-executado após mudança na feature, adicionar um novo arquivo com a data atualizada — não sobrescrever o anterior. Isso preserva histórico de "como a feature se comportava em cada momento".
